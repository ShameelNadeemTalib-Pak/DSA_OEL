Online Shopping and Order Management System (CS-250 OEL)
CMS ID 534746 - Humayun Azam - BESE 31 D

How to run (Visual Studio): create an empty C++ Console project, add main.cpp,
build and run. Copy products.txt, inventory.txt and orders.txt into the project
working directory (where the program runs) to start with the sample data.
Delete these files to start with empty records.

Data structures: linked list (products), stack (cart), queue (orders)
Algorithms: linear search, bubble sort
Files: products.txt, inventory.txt, orders.txt, processed_orders.txt
